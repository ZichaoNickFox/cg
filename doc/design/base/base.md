# base 设计

## 1. 模块组成
`base/` 当前由以下部分构成：

- `debug.h`：断言与日志宏
- `util.h/.cc`：文件、字符串、时间、容器辅助
- `math.h/.cc`：采样、噪声、随机与数值工具
- `geometry.h/.cc`：CPU 侧几何结构与相交逻辑
- `color.h`：共享颜色定义

## 2. 设计要点
- `cg_debug` 作为 interface target 暴露调试设施，`cg_base` 作为静态库暴露基础实现。
- `util` 中的大量模板函数保持头文件内联，减少样板胶水代码。
- `geometry` 只描述 CPU 侧几何和数学关系，不感知 renderer 的 GPU 资源对象。
- `math` 同时承担实验场景中的采样辅助，例如半球采样和随机噪声生成。

## 3. 边界
- 本目录不负责图形 API 封装。
- 本目录不持有全局运行时状态。
