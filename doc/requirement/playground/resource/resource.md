# playground/resource 需求

## 1. 目标
`playground/resource/` 目录保存运行时模型、纹理和局部说明文件，服务实验场景加载。

## 2. 范围
- `model/`
- `texture/`
- `shadow_scene/`

## 3. 功能需求
- 目录中的资源路径应保持稳定，供 `config.pb.txt`、模型加载器或场景代码引用。
- 资源应按类型分目录存放，避免代码、shader 和运行时资产混放。
- 说明性文件可放在资源子目录中，用于解释资源来源或场景使用方式。

## 4. 验收要点
- 场景引用到的资源路径在仓库内可解析。
